Bước 1 Giải nén và Chuẩn bị
1. Giải nén file ZIP này vào một thư mục bất kỳ.
2. Mở TerminalCommand Prompt và di chuyển vào thư mục vừa giải nén.

Bước 2 Cài đặt Thư viện
1. Cài đặt các thư viện cần thiết
   pip install -r requirements.txt

Bước 3 Khởi chạy Ứng dụng
1. Chạy file app.py
   python app.py

2. Mở trình duyệt web của bạn và truy cập vào đường link cục bộ hiển thị trên Terminal (thường là http127.0.0.17860).
